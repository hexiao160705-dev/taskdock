# Roadmap

These are directions, not release dates or promises.

## Current foundation

Versioned task capabilities; reusable child DAGs; private invocation trees; scoped authorization; durable attempts and receipts; human waits; ACK/NACK inbox; reviewed learning proposals; self-hosted capability registry.

## Open-source launch

- English-first documentation with Chinese companion.
- English / Simplified Chinese control plane and Registry, preserving user-authored content.
- MIT license and public-source audit; publication is verified separately from code preparation.

## Next validation priorities

- One real task with an explicitly configured provider and measurable result quality.
- External-tool idempotency declarations and business-specific reconciliation.
- Portable dependency bundles for composite capabilities.
- Retention policies and deployment hardening.
- Accessible onboarding and community-provided integration examples.

## Later exploration

Optional push adapters, publisher identity/signatures, distributed workers, parallel teams, and A2A adapters. A hosted multi-tenant marketplace requires additional security and product work.
