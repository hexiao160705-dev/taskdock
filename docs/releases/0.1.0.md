# 0.1.0 · TaskDock 首个本地 DEMO

日期：2026-10-31。状态：私有评审版本；不公开发布。

## 需求原话

“我需要一个以任务类型为对象（不是以角色为对象）的管理平台”；“每一个请求的会话应该都是独立的，只是共享底层能力，但是上下文不能交叉污染”；“测试版用来调试，正式版提供服务，需要有 git 功能”；“一部分是本地端……另一部分应该是云端，大家可以共享自己的任务 AI”；“中间不用问我，把问题留到一起跟 DEMO 一起提交给我”；代码同步个人 GitHub，确认满意前不公开。

## 方案

核对 10 个 GitHub 候选后，未核实到完整覆盖需求的现成平台。自建本地控制面，复用 Pi 1.4.0、官方 MCP SDK、SQLite 和 Git。任务类型为目录对象，请求 capability 为调用方边界，固定能力快照为执行边界，知识提案审核为学习边界。独立 Registry 服务和网站验证本地/云端分工，尚未上公网。

## 动作

实现任务目录、配置编辑、独立请求、历史管理、事件归档、受控能力加载、单 Agent/串行 Team、真实 Git 版本与回滚、精确摘要测试晋级、MCP HTTP/stdio 入口和调用 Skill、用户定义学习规则与审核、IANA 时区调度、能力包分享/安装、独立 Registry 页面、备份、后台启停和部署入口。文档记录架构、契约、调研来源、集中问题和验证盲区。原始历史、.env、备份与浏览器产物排除在 Git 之外。
