# TaskDock 0.3.0 — bilingual MIT preview

## Request

English and Chinese product; English-first project introduction with Chinese companion; publish to GitHub and make the project public under MIT.

## Design

Translate authored interface literals only. Keep capability configuration, raw diagnostics, inputs, answers, model outputs and history in their original language. Locale choices are stored per service origin. Language switching is outside open editing dialogs.

## Changes

English-first README, Chinese companion, English technical guide, MIT license, contribution and security guidance, issue/PR templates, bilingual control plane and Registry, translation coverage check and localized HTTP status summaries.

## Verification

The bilingual baseline passed 40 browser layout samples (10 pages × two languages × two viewports), Registry switching and preservation of Chinese input in an English form. No unhandled page errors were reported. Backend/protocol/offline SDK regression passed 44 checks. Final release verification and publication receipt are maintained in OPEN-SOURCE-RELEASE.md. These checks are not live-model evaluation, human acceptance or physical-phone testing.
