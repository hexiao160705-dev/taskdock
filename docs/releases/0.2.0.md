# TaskDock 0.2.0 — 授权、持久执行和任务图

2026-11-01。本机分层验收完成，保持本地单维护者 DEMO，无公开部署。代码以本地 `v0.2.0` 留痕；私有 GitHub 同步核对源码 tree SHA，不改变仓库可见性。具体提交以本次交付链接和 Git 记录为准。

## 需求原话

“继续开发 TaskDock，先补齐授权、持久执行恢复、可靠投递和人工等待机制。……完成后把 DEMO、测试结果和待确认问题一起提交，代码同步到私有 GitHub，暂时不要公开。”任务应分层，多个父任务共享子任务，也能微调成新子任务。

## 方案

能力是 DAG，请求是私有树；父能力固定引用子 releaseId/digest。服务签发 Mandate，客户端只能缩小范围，动作前持续复核。SQLite 事务记录 Run/Attempt/Effect/Outbox，租约与 fence 防止旧尝试写回。阶段 checkpoint 与本次工具回执用于恢复，不确定副作用必须核对。结构化问题独立保存，全部回答后恢复。消息拉取至少一次，按 ID 去重并 ACK。

## 动作

新增任务图与来源派生、最小输入映射、祖先授权复核、撤权、持久队列、失败预算、阶段恢复、工具 intent/receipt、人工待办和收件回执页面。MCP 从 7 项扩为 12 项。保留正式版本发布和经验审核；旧能力包摘要先验证再加默认值。导入包清除外部连接和密钥引用，复合包跨实例依赖暂拒绝。

保存草稿仅更新非编辑区域，修复异步回包重建子任务表单导致的选择/焦点丢失。文件归档在业务事务提交后投影，失败可从 SQLite 重建，健康检查暴露待补写数量。

## 实测

本次 `npm ci` 退出 0；后端/协议/离线 SDK 共 **44 项测试通过**，包含 3 项真实 SIGKILL 子进程恢复场景：checkpoint、已提交工具回执、外部成功但未提交回执。最后一种进入核对，未重复动作。实际 Pi SDK 使用模拟 provider 响应，不宣称 live-model 验证。

浏览器完成同请求跨服务重启、人工回答、私有子输入、ACK/重投、真实派生换绑与精确摘要发布门禁；延迟实际 PUT 响应后编辑节点/焦点/选择保留。10 页面×2 视口几何检查及截图审读；移动视口不是手机真机。本机 Chrome 原生 UI 完成正式调用、必填错误、键盘/中文粘贴、回答恢复、独立子请求和 3 条消息 ACK；这仍是原生 UI 自动化，不是人工验收或物理输入法验收。
