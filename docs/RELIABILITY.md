# TaskDock 0.2 — 可靠执行与任务关系契约

状态：实现契约，2026-11-01。对应用户接受 B 方案的开发目标；本文件在实现前建立，验收结果另记。目标是补齐授权、持久恢复、可靠投递、人工等待，以及可共享和派生的分层任务。

## 任务类型图与请求树

能力目录是有向无环图（DAG）：多个父 TaskType 可以引用同一个子 TaskType。界面按树展开，共享节点标明引用次数。`children[]` 保存唯一 key、taskId、releaseId、digest 和显式 inputMap；引用必须是已发布的不可变版本，禁止环、超深或无限展开。升级子任务不会静默更新父任务。派生是复制指定正式版本到新的 TaskType 草稿，保留来源 taskId/releaseId/digest，独立测试和发布。

每次父请求产生自己的 Run 树：每个子调用创建新的私有 Run、快照、事件和产物。父任务只收到已声明的子调用结果，不读取其他父请求或其他子节点的原始材料。输入映射仅为固定字段路径，不执行表达式。根请求创建时保存整个引用图快照，恢复时不用环境中的新配置。父任务的检查/模型执行在子任务完成后开始。

## 授权

session capability 负责身份和请求归属；不可变 Mandate 负责一次请求允许的动作、子任务、工具、调用预算、尝试上限和截止时间。服务依据固定能力图签发授权，调用方只可缩小范围，不能借输入或模型文字扩权。子调用继承根授权的交集；全树共享工具预算。

每任务另有可变的启用/暂停控制，单请求可撤销。派工、恢复、子调用、工具执行、回答与重试前均复核；能力版本固定不妨碍撤权。工具只来自已固定 MCP allowlist，不载入主目录 Agent 设置。此授权边界不冒充 OS 沙箱。

## 持久执行与恢复

SQLite 是状态源。提交事务同时保存 Run、Mandate、能力图快照和 execute Effect。Attempt 是一次执行尝试，保存 owner/fence/lease；心跳续租，过期或确认死亡的执行器可被恢复。状态变更要求当前 Attempt 所有权，旧执行器不能写入新尝试。

重启不会将队列或人工等待丢失。确定性检查可重放；Pi 已完成阶段有持久 checkpoint，恢复只载入本次请求的 checkpoint、人工回答和工具回执。外部工具调用前先持久记录 intent，成功后记录 receipt。若崩溃落在外部成功与回执持久化之间，转为 reconciliation 等待，不能盲目重复副作用。明确失败的尝试可由调用者重试，受预算和授权限制；取消不会自动恢复。

## 人工等待

`waiting_human` 是非终态。Attention 保存问题、字段类型、必填项、类型和来源；回答单独保存，不改原始请求、能力或 Mandate。同一回答幂等，不同重复回答冲突。可由配置中的 humanGate 或 Pi 的受控请求工具触发。收到回答后重新校验授权并排队，使用同一个 Run、新 Attempt。工具结果不确定时需明确核对“已执行并记录结果”或“确认未执行才可重试”。回答者身份按实际 session/维护者记录，不伪称已证明真人身份。

## 可靠投递

终态与待人处理状态在业务事务中写入 Outbox。父会话通过 HTTP/MCP durable inbox 拉取，收到租约回执后 ACK；断线/租约过期重投同一 message ID，显式 NACK 退避。ACK 持久且幂等。语义是至少一次投递，消费者按 message ID 去重；不宣称跨外部系统 exactly-once。无需暴露回调地址或另授外网访问权限。

## 边界与兼容

既有 stable-only API、精确 digest 发布、Git、经验提案和单请求隔离保留。0.1 数据库按列/表增量迁移，迁移前备份；旧中断请求不无依据自动重放。单机 SQLite 与协作取消仍不构成分布式或恶意插件执行保障。复合任务的跨实例能力包依赖分发先显式拒绝，防止把本机 release ID 当作可移植依赖；独立能力包原有往返继续工作。

## 验收必须覆盖

1. 授权缩小、越权拒绝、撤销后重启/恢复仍受限、子任务预算继承。
2. 真实子进程中止与重启：队列恢复、Attempt 留痕、能力版本不漂移。
3. 工具成功但回执丢失：出现人工核对，无盲目第二次调用。
4. Outbox 事务一致、断线重投、ACK 幂等、NACK 退避与跨 session 隔离。
5. 人工问题跨重启保留，回答校验、冲突处理、恢复后结果可追溯。
6. 两个父类型共享一个子能力但请求上下文独立；派生有来源、无隐式改写；环被拒绝。
7. 原有发布、MCP HTTP/stdio、Pi 隔离、Registry 与定时功能回归。
8. 桌面浏览器自动化与原生本机核心流程；输入首焦、轮询不打断输入、布局无遮挡；报告测试层与未验证项。
